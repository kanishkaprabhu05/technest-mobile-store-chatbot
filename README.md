# 📱 TechNest Mobile Store - AI Customer Support Chatbot

A simple AI customer support chatbot built with Python and Streamlit for Trinoix Project.

## ✨ Features
- Answers about products (iPhone, Samsung, OnePlus, Redmi, Laptop)
- Price, stock availability, warranty details
- Order tracking, delivery info, return policy, store location
